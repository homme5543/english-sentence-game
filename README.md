# Sentence Hero

초등 영어 4학년 11개 단원의 핵심 표현을 문장 문제로 익히는 웹 게임입니다. [재구성 계획](GAME_REDESIGN_PLAN.md)에 따라 단원마다 일반 문제 10개와 보스 문제 3개, 총 143개 문제를 제공합니다.

## 문제 유형

- 영어 문장을 보고 한국어 의미 4개 중 선택
- 영어 문장의 빈칸을 4지선다 또는 단답으로 채우기
- 그림을 보고 일치하는 영어 문장 4개 중 선택

정답을 맞히면 별을 얻고 몬스터에게 피해를 줍니다. 틀리면 몬스터가 체력을 회복하고 정답을 밝히지 않는 힌트를 보여 줍니다. 일반 문제는 선택지 순서를 바꿔 다시 풀 수 있습니다. 보스 문제 3개 중 2개 이상 맞히면 다음 단원이 열립니다.

## 실행

별도 빌드와 외부 라이브러리가 없습니다. `index.html`을 열거나 정적 파일 서버로 폴더를 제공하면 됩니다.

```sh
python -m http.server 8765
```

학습 진도는 해당 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터 삭제나 다른 기기로 이동하면 진도가 이어지지 않습니다. 현재 버전에는 학생 계정 및 서버 동기화가 없습니다. 기존 `code.gs`는 이전 영단어 게임의 Google Apps Script 코드이며 새 게임에서 사용하지 않습니다.

## 확인

```sh
node --check game.js
node tests/content.test.js
```
